Freight Shipping Audit

Item module · v1.0 · Products over 80 lb

Check live eBay listings for negotiated freight. Audits continue on the server when this page is closed.

eBay setup and shipping corrections

Add production eBay credentials in Render: EBAY_CLIENT_ID, EBAY_CLIENT_SECRET, and EBAY_REFRESH_TOKEN from seller OAuth consent. Use the general scope https://api.ebay.com/oauth/api_scope. Alternatively, EBAY_USER_ACCESS_TOKEN works until it expires. These are separate from your SellerChamp token.

Use your actual seller account. The audit reads eBay; it does not modify eBay. Open the Product in SellerChamp to change freight shipping there, let it synchronize, then tap Recheck eBay. A direct SellerChamp freight button will require its shipping update API to be verified.

Missing weight and missing eBay IDs are reported; they cannot be certified as safe. This audit uses SellerChamp item weight in pounds, with package weight as a fallback. Only a live active listing with ShippingType FreightFlat and no free-shipping option passes.
